# Simple HUD (Fabric 1.21.4)

HUD w lewym górnym rogu: FPS, koordynaty XYZ i wytrzymałość zbroi.

## Jak dostać plik .jar przez GitHub
1. Utwórz nowe repozytorium na GitHubie i wrzuć do niego CAŁĄ zawartość tego folderu
   (razem z ukrytym folderem .github).
2. Wejdź w zakładkę Actions i poczekaj, aż "Build mod" zakończy się zielonym znaczkiem.
3. Kliknij ten przebieg i na dole pobierz artefakt "simplehud-mod".
4. Rozpakuj go. Plik BEZ "-sources" w nazwie to mod.

## Instalacja
- Fabric Loader dla 1.21.4
- Fabric API 0.119.2+1.21.4 (Modrinth) w folderze mods
- simplehud-1.0.0.jar w folderze mods
